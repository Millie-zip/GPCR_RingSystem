### N5：epsilon 输出仍有与高斯噪声目标不相容的幅度硬上限

- 状态：暂缓。用户明确要求暂时不修改；未新增 epsilon 输出头或更改现有模型权重结构，本问题仍未修复。
- 位置：`models/equivariant/layers.py:43-47,137-149`；`models/equivariant/backbone.py:537-545`。
- 原因：每层坐标消息是单位方向乘 Tanh 标量，再乘 scale，并按 degree 取平均；单层位移范数不超过 scale。epsilon 直接由累计位移得到。无固定锚点、去中心后的保守上限为 `2 × 层数 × scale`；有锚点、不去中心的上限为 `层数 × scale`。
- 当前默认：3 层、scale=0.1，无锚点上限 0.6。复现的 2 层模型上限 0.4，而同一小型 batch 投影噪声目标最大范数约 1.812697。该结构限制不会通过增加 epoch 消失。
- 建议：将稳定的内部坐标更新与等变 epsilon 输出头分开，或明确设计并验证目标与输出缩放。此次没有测量真实训练集的不可约 loss，也没有开展长期收敛实验。

### N8：恢复训练重置 best loss，较差模型会覆盖原 best checkpoint

- 位置：`training/trainer.py:308-324,352-355`。
- 复现：第一阶段 best validation=0.1；恢复后首个 validation=0.9，`best.ckpt` 从 epoch 0 被覆盖为 epoch 1。epoch loss 在此次复现中被受控替换，模型、checkpoint 保存与恢复逻辑使用实际实现。

- 建议：保存并恢复历史 best 指标和对应 checkpoint 身份；校验恢复目录与运行版本，避免无训练迭代时输出虚假的完成状态。

### N12：固定采样 seed 不能跨进程复现 RAscore 补样

## 安全与资源边界观察

静态检索未发现有证据支持的远程代码执行或 SQL 注入结论。YAML 安全加载、checkpoint 的 `weights_only=True`、参数化 SQL、使用参数列表启动子进程应保留。这个结论只覆盖检查到的入口，不代表所有依赖无漏洞或未来公开服务已经具备安全边界。

`training/checkpoint.py:8-13` 的路径 helper 未限制 name 为 basename，传入 `../escape` 会返回目录之外的路径。此次仅核对返回值，没有写出目录外文件；目前没有生产调用链使用该 helper，因此未作为可外部利用的漏洞或主问题计数。接入不可信名称前应限制分隔符、绝对路径及最终目录。

CPU bfloat16 autocast 当前仍在 `models/equivariant/layers.py:123` 复现 dtype 不同的 index_add_ 错误。当前训练配置明确仅允许 FP32/FP64，所以将其记录为 AMP 接入限制，不当作默认训练已失败。CUDA FP16 未验证。

`pocket/fields.py:466-495` 仍构造 B×Q×P 的两两距离中间结果；真实 OOM 没有复现。`preprocessing/diffusion_dataset/build_stage3_assets.py:596` 的外部对接调用没有自身 timeout，尽管前面的构象子进程有 timeout；未实际运行对接，需检查所用外部程序的时间限制。这两项是资源/阻塞风险，不能写成已发生事故。

## 已验证的正面结果与旧结论修正

当前训练循环可以创建 optimizer、反向传播、保存并恢复模型。已有真实坐标物化接口，不能再把 Dataset、collate 和训练一概写成占位实现。固定坐标 diffusion mask、无类别的旧版图以及可配置 Route A 词表的合并回归测试通过。固定锚点会被保留，不能继续用旧的“所有输入都单独居中、完全丢失相对平移”概括当前实现。

RAscore 训练/验证表的 molecule UID、isomeric SMILES、nonisomeric SMILES、chemical UID、topology UID 五个字段精确交集均为 0；三份 teacher 表与原始搜索结果的 solved 字段一致。没有证据说这些现有划分发生了已确认的数据泄漏。JSONL 物化过程会写入按分子分组的 split_group；外部自行准备的记录若缺少该字段，Dataset 会回退到 sample_id，仍需在使用前明确分组规则。

RAscore 的 solved 是特定 policy、stock 和搜索预算下的结果，不是实验合成标签；搜索失败也不等于化学上不可能合成。模型 score 的可读取性不证明它是已校准的合成概率。
